# Mock Exams

Last verified: 2026-11-24.

- `mock1.md` — 65 questions, 90 minutes, timed
- `mock2.md` — 65 questions, 90 minutes, timed
- `review.md` — every wrong answer, why the right answer wins, which task statement to re-study

Rules for good mocks:
- Match the weights: about 13 questions D1, 16 D2, 18 D3, 9 D4, 9 D5 (of 65).
- Mix multiple choice and multiple response.
- Official AWS pages list multiple choice and multiple response. Some third-party sites also list ordering, matching and case-study questions. Add a few of these types so you are ready (not confirmed by AWS).
- Include questions on the new guide topics: agentic AI, MCP, context engineering, prompt caching, model distillation, LLM-as-a-judge.
- Tag every question with its task statement (for example, `3.4`) so the scoreboard works.
- Mark which questions are unscored practice. The real exam has 15 unscored questions you cannot see.
