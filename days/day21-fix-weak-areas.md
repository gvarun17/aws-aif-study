# Day 21 — Fix Weak Areas

- Domain: all
- Task statements: your weakest ones
- Time needed: 3 hours
- Last verified: 2026-11-24

## Goal

Raise every task statement to 80% or more before the mock exams.

## Steps

1. Open `scoreboard.md`. Sort the task-statement table by lowest % correct.
2. Pick the lowest **three** task statements. If D3 (28%) has any weak statement, put it first.
3. For each one:
   1. Re-read the lesson (30 minutes). Redraw its diagram from memory.
   2. Write a 5-line summary in your own words.
   3. Redo the lesson questions and the related review-day questions.
   4. Ask the coach for 5 **new** questions on that task statement. Include 2 multiple response.
   5. Log the new score.
4. Update `cheatsheets/service-picker.md` with any scenario you got wrong.
5. Write down your top 10 "trap" phrases. Examples: "least operational effort", "no ML expertise", "private data without retraining", "business users", "developers".
